## 主題一：高盛報告 — AI 利潤奇點

**核心推論：**
- Token 售價下跌趨勢已趨緩（2025年底開始平穩），但 Token 成本仍以每年 60-70% 速度持續下降
- 兩條線的剪刀差 → 雲端服務商的邊際毛利正在急速擴大，**毛利拐點預計在未來 3-12 個月出現**

**Agentic AI 帶來的用量爆炸：**
- 一般聊天：~1,000 Token/次；Always-on Agent：每天可超過 100,000 Token
- 預估 2030 年全球 Token 需求是 2026 年的 **25 倍（+2,400%）**
- 企業端最終將佔全球 Token 用量 **70% 以上**，成長潛力達 55 倍（至 2040 年）

**正向飛輪：** 成本降低 → 更強 Agent → 更高用量 → 更高利潤 → 再投入優化，與過去「用越多、虧越多」的悲觀劇本完全相反

**結論：** 這是「營收爆發 × 毛利擴張」的乘積效應，兩個引擎同時點火

## 主題二：Agent 帳單，企業付得起嗎？

**微觀 ROI 對比（每日 AI 成本 vs 人力日薪）：**
- 程式開發 Agent：$13.39 vs $300 → **ROI 極佳，最快落地**
- 資料輸入 Agent：$59.68 vs $80 → 具商業可行性
- 客服中心 Agent：$92.90 vs $90 → **目前不划算**（多模態轉換成本高，外包人力便宜）

**反直覺結論：** AI 取代軟體工程師，可能比取代客服更快

**「把餅做大」邏輯：** AI 的價值不只是省錢，而是釋放「未滿足需求」（如零等待客服），讓服務量指數爆發

**企業採用現況：**
- 70-90% 企業在「實驗」AI，不到 25% 真正規模化部署
- 阻礙不是技術，是**組織問題**（信任、資安、ROI 可見性）

**高盛預測：S 型曲線，15 年到頂，巔峰滲透率 35-40%**
- 現在處於底部醞釀期，2030 年前後進入陡升加速期
- 35-40% 的知識工作被滲透，市場規模仍是全球軟體業年收的 5 倍以上

## 主題三：高盛「九大贏家」框架

**名單（半導體 + 雲端 + 軟體）：**
Broadcom、Nvidia、AMD、Amazon、Google、Meta、Microsoft、Cloudflare、Accenture

**四條能力軸（選股框架）：**
1. 壓低 Token 成本（Broadcom 最貼合，客製化 ASIC）
2. 處理巨量規模（Amazon、Google、Meta）
3. 在高 ROI 文字 workflow 賺錢（Microsoft、Cloudflare）
4. 在採用曲線加速期接單（Accenture）

**最大商業模式顛覆：** SaaS 從「賣人頭（Per-Seat）」→「賣工作量（Units of Work）」，TAM 從「全球軟體預算」擴張到「全球白領薪資池」

**KP 的核心觀點：** 名單是副產品，框架才是真正的資產

## 主題四：CPU 復興被財報確認

**三家公司財報重點：**
- **AMD**：伺服器 CPU 年增 50%+，Lisa Su 將 2030 年市場規模預測從 $600 億直接翻倍至 **$1,200 億**，CAGR 從 18% 升至 35%+
- **ARM**：資料中心版稅收入年增超一倍，AGI CPU 需求已超 $20 億，但版稅略低於預期導致股價下跌
- **Intel**：謹慎樂觀，成功拿下 NVIDIA 下一代 DGX 系統主機 CPU 位置

**x86 vs ARM 之爭：**
- AMD 主張：單顆 CPU 吞吐量是 ARM 的 2 倍（單機效能）
- ARM 主張：同樣機架空間效能是 x86 的 2 倍（能源/空間效率）
- 兩者針對不同市場，現階段不是零和競爭，**餅在一起變大**

**結論：** 現在三家都說需求跑在供給前面，短期贏家就是「能出貨的人」

## 主題五：Anthropic 和 OpenAI 部署「地面部隊」

**核心問題：** 企業買了 API，但不知道怎麼落地 → 光賣 API 不夠

**解法：Forward Deployed Engineer（FDE）** — 複製 Palantir 的打法
- 派頂尖工程師進駐客戶公司，直接寫生產級代碼、整合系統、處理髒活
- 最終目標是知識轉移，讓客戶能獨立維運

**規模化動作：**
- **OpenAI**：成立「The Deployment Company」合資企業，估值 $100 億，聯合 TPG、Brookfield 等私募，滲透其投資組合公司
- **Anthropic**：與 Accenture 簽多年合約（訓練 3 萬名員工），並與 Blackstone、Goldman Sachs 成立 $15 億新公司，專攻**中型企業**

**影響：**
- 企業 AI 採用率將加速，「試點煉獄」問題被直接攻破
- AI 公司定位從「模型供應商」→「企業轉型夥伴」
- 收入結構改變（API + 高價值服務），客戶黏性大幅提升
- 短期最直接受益者：**Accenture** 等系統整合商

**與 Palantir 的關係：** 既競爭又互補。Palantir 做數據治理底層，OpenAI/Anthropic 提供智能大腦，高端客戶可能同時用兩者，但長期會在企業 AI 預算上正面交鋒

## 整體結論

AI 的故事正從「希望它能賺錢」轉向「它已經開始賺錢，而且會越賺越多」。但這是一場 S 型曲線的長期遊戲，真正的爆發點在 2027-2030 年，現在是底部醞釀期，需要耐心。

> 找出「短期已經有帳單跑得過」+「長期站在 S 曲線陡升段受益位置」的公司，拿得住，拿得久。
