# 報告與交付契約

## 輸出與聲明

輸出 `output/latest.html`、`output/tw_stock_momentum_report_YYYYMMDD.html`、`output/data/report_YYYYMMDD.json`。兩份 HTML 對應同一報告，JSON 是機器可讀來源。

HTML 頂部及底部均顯示：

> 本報告僅供量化篩選、資訊整理與研究用途，不構成投資建議、買賣邀約或報酬保證。歷史行情、法人籌碼及技術訊號不保證未來結果。使用者應自行確認資料並承擔投資風險。

## HTML 內容

摘要顯示報告名稱、各資料日期、取得時間與時區、掃描／初篩／強勢／觀察／資料不足數量、模式、來源、缺失及估算警告。

互動篩選提供代號／名稱、市場、最低投本比、成交量、最大資本額、最少連買日、最低總分、多頭排列、評級及資料狀態。排名依投本比、連買日、成交量、資本額、總分排序，須用原始數值。

排名欄位至少包含身份、市場、日期、收盤、漲跌幅、成交量、20 日量比、資本額、發行股數、當日投信張數、投本比、連買日、近 3 日投信與外資、實際持股比例或明示的累計估算、MA5／10／20、距 20 日高點、訊號、風險、分項分數、總分、評級、可信度及展開圖表按鈕。

## 圖表與分析卡

每檔顯示至少 60 個實際交易日的日 K、MA5／10／20、成交量、20 日高點或可驗證平台、每日投信及外資柱、入選日、參考進場、初始停損與移動停利線。Tooltip 顯示日期、OHLC、漲跌幅、成交量、投信、外資及投本比。資料不足顯示實際筆數，不得補造。使用 CDN 時標示離線限制；完全離線則將函式庫放入 `output/assets/`。

每檔分析卡顯示入選原因、偏弱條件、籌碼與技術摘要、K 線風險、條件式計畫、失效條件、來源、實際／估算／缺失欄位及可信度。

## JSON 契約

頂層保存 `schema_version`、報告識別、模式、產生時間與時區、各資料日期、來源、警告、門檻、統計、排除原因及候選。候選保存身份、市場、日期、原始輸入、衍生指標、法人與 OHLCV 歷史、篩選結果、分項分數、總分、評級、訊號、風險、條件式計畫、可信度、缺失／估算欄位及來源。保留精度並定義股、張、元及百分比。

## 視覺、安全與交付

台股慣例：漲／買超／強勢紅色，跌／賣超／弱勢綠色，警戒橘色，缺失灰色。支援桌面與手機。對名稱、文字、URL 與外部輸入 escape；安全序列化 JavaScript，防止 `</script>` 與 HTML 注入。主要內容不依賴後端。

最終回報交易日期、掃描與入選數、前 5 名代號／名稱／投本比／總分／一句原因、缺失與警告、HTML 及 JSON 實際路徑或已確認連結。失敗時明說原因；未經授權不得自行發布。

## Schema 2.0 降級揭露

正式 `report_YYYYMMDD.json` 保存 scores、prices、history 三層 bundle。技術缺失候選仍出現在排名表，但 HTML 顯示警告及「無技術圖」，不得顯示交易計畫。`counts.technical_missing` 必須與逐檔 `technical_status=missing` 數量一致。
