# 股票分析報告輸出格式

本文件定義標準化報告格式，所有 bot 輸出必須嚴格遵守此格式。

---

## 檔案命名規則

```
{公司名稱}({股票代號})_analysis_{YYYYMMDD}.md
存放路徑：/home/agent/notes/stock-analysis/
```


## 注意事項

1. **基本面**：區分本業 EPS 與合併 EPS，一次性事件不計入估值
2. **技術面**：所有數值必須實際計算，不得估算或捏造
3. **結論**：必須有明確的 Do / Don't，不能只說「觀察」
4. **機率**：三個情境機率加總必須等於 100%
5. **存檔後**：必須 push GitHub 並 mention <@1331833906751869030>
