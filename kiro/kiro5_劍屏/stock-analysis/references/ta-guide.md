# 技術指標計算規則

本文件定義所有技術指標的計算方式與訊號判斷邏輯，供任何 bot 照規則執行，不依賴主觀判斷。

---

## 資料準備

從 TWSE API 取得近 3 個月日K數據，欄位：
- `date`：日期（民國年格式，需轉換）
- `open`、`high`、`low`、`close`：OHLC
- `volume`：成交股數（張 = volume / 1000）

**最少需要 60 個交易日**才能計算 MA60。若不足，跳過 MA60 相關計算。

---

## 一、移動平均線（MA）

### 計算方式
```
MA(n) = 最近 n 日收盤價的算術平均
MA5  = 最近 5 日收盤均價
MA20 = 最近 20 日收盤均價
MA60 = 最近 60 日收盤均價
```

### 訊號判斷
| 狀況 | 判斷 |
|------|------|
| 收盤 > MA5 > MA20 > MA60 | 強勢多頭排列 |
| 收盤 > MA5 > MA20，MA60 未知 | 短中期多頭 |
| 收盤 < MA5 < MA20 < MA60 | 強勢空頭排列 |
| MA5 由下往上穿越 MA20 | 黃金交叉（買訊） |
| MA5 由上往下穿越 MA20 | 死亡交叉（賣訊） |

---

## 二、均線型態觀察

### 糾結判斷
```
糾結條件：abs(MA5 - MA20) / MA20 < 0.02 且 abs(MA20 - MA60) / MA60 < 0.02
（三線價差均在 2% 以內）
```

### 型態分類
| 型態 | 條件 | 意義 |
|------|------|------|
| 強勢多頭 | MA5 > MA20 > MA60，且各線向上 | 趨勢明確向上 |
| 弱勢多頭 | MA5 > MA20 > MA60，但部分線走平 | 多頭但動能減弱 |
| 強勢空頭 | MA5 < MA20 < MA60，且各線向下 | 趨勢明確向下 |
| 弱勢空頭 | MA5 < MA20 < MA60，但部分線走平 | 空頭但動能減弱 |
| 糾結整理 | 三線價差 < 2% | 方向不明，等待突破 |
| 多空交戰 | MA5 與 MA20 反覆交叉 | 震盪，不宜追高殺低 |

### 均線方向判斷
```
向上：當日 MA > 5日前 MA（正斜率）
向下：當日 MA < 5日前 MA（負斜率）
走平：差距 < 0.5%
```

## 三、布林通道（Bollinger Bands）

### 計算方式
```
中軌 = MA20
標準差 σ = sqrt( Σ(close_i - MA20)² / 20 )
上軌 = MA20 + 2σ
下軌 = MA20 - 2σ
帶寬 = (上軌 - 下軌) / 中軌 × 100%
```

### 訊號判斷
| 狀況 | 判斷 |
|------|------|
| 收盤 > 上軌 | 突破上軌，短線超買，注意回測 |
| 收盤 < 下軌 | 跌破下軌，短線超賣，注意反彈 |
| 收盤在中軌上方 | 偏多 |
| 收盤在中軌下方 | 偏空 |
| 帶寬 < 10% | 布林收縮，即將大幅波動 |
| 帶寬 > 30% | 布林擴張，趨勢明確 |

## 四、RSI（相對強弱指標）

### 計算方式（Wilder 平滑法）
```
每日漲跌：D_i = close_i - close_{i-1}
上漲幅度：U_i = max(D_i, 0)
下跌幅度：L_i = max(-D_i, 0)

初始平均：
  AvgU_14 = Σ(U_1..14) / 14
  AvgL_14 = Σ(L_1..14) / 14

後續平滑（Wilder）：
  AvgU_i = (AvgU_{i-1} × 13 + U_i) / 14
  AvgL_i = (AvgL_{i-1} × 13 + L_i) / 14

RS = AvgU / AvgL
RSI = 100 - 100 / (1 + RS)
```

### 訊號判斷
| RSI 值 | 判斷 |
|--------|------|
| > 80 | 嚴重超買，高風險 |
| 70～80 | 超買區，注意回調 |
| 50～70 | 偏強，多方主導 |
| 30～50 | 偏弱，空方主導 |
| 20～30 | 超賣區，注意反彈 |
| < 20 | 嚴重超賣 |

## 五、MACD

### 計算方式
```
EMA(n) 指數移動平均：
  EMA_1 = close_1
  EMA_i = close_i × k + EMA_{i-1} × (1-k)，k = 2/(n+1)

DIF（快線）= EMA(12) - EMA(26)
DEA（慢線/Signal）= EMA(DIF, 9)
Histogram（柱狀）= DIF - DEA
```

### 訊號判斷
| 狀況 | 判斷 |
|------|------|
| DIF 由下往上穿越 DEA（零軸上方） | 強勢買訊 |
| DIF 由下往上穿越 DEA（零軸下方） | 弱勢買訊 |
| DIF 由上往下穿越 DEA | 賣訊 |
| Histogram 連續擴大（正值） | 多頭動能增強 |
| Histogram 連續縮小（正值） | 多頭動能減弱 |
| Histogram 由負轉正 | 趨勢轉多 |

## 六、KD 隨機指標（Stochastic）

### 計算方式
```
週期 n=9，平滑 m1=3，m2=3

RSV_i = (close_i - min(low, 9日)) / (max(high, 9日) - min(low, 9日)) × 100

K_i = K_{i-1} × (2/3) + RSV_i × (1/3)
D_i = D_{i-1} × (2/3) + K_i × (1/3)

初始值：K_0 = D_0 = 50
```

### 訊號判斷
| 狀況 | 判斷 |
|------|------|
| K > 80，D > 80 | 超買區，注意賣出 |
| K < 20，D < 20 | 超賣區，注意買入 |
| K 由下往上穿越 D（低檔） | 黃金交叉，買訊 |
| K 由上往下穿越 D（高檔） | 死亡交叉，賣訊 |
| K、D 同向向上 | 多頭趨勢 |
| K、D 同向向下 | 空頭趨勢 |

---

## 七、成交量均線（MAV）

### 計算方式
```
MAV5  = 最近 5 日成交量（張）均值
MAV20 = 最近 20 日成交量（張）均值
MAV60 = 最近 60 日成交量（張）均值
```

### 訊號判斷
| 狀況 | 判斷 |
|------|------|
| 當日量 > MAV5 > MAV20 | 量能放大，趨勢確認 |
| 當日量 < MAV5 < MAV20 | 量能萎縮，趨勢減弱 |
| 價漲量增 | 健康上漲，可信度高 |
| 價漲量縮 | 上漲動能不足，注意 |
| 價跌量增 | 賣壓沉重，偏空 |
| 價跌量縮 | 跌勢趨緩，可能止跌 |
| 爆量（當日量 > MAV20 × 2） | 重大事件，需結合價格方向判斷 |

---

## 八、計算順序

執行時依以下順序計算，避免依賴未計算的值：

1. 整理收盤價序列（時間正序）
2. 計算 MA5、MA20、MA60
3. 計算布林通道（基於 MA20）
4. 計算 RSI(14)
5. 計算 EMA12、EMA26 → MACD
6. 計算 KD(9,3,3)
7. 計算 MAV5、MAV20、MAV60
8. 判斷均線型態（基於 MA5/20/60）
9. 彙整所有訊號 → 輸出

---

## 九、關鍵價位識別

```
近期高點：過去 20 日最高價的最大值
近期低點：過去 20 日最低價的最小值
主要壓力：近 60 日內出現 2 次以上的高點區間（±1%）
主要支撐：近 60 日內出現 2 次以上的低點區間（±1%）
```
